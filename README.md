# Milkii's dotfiles, personal configuration management using Stow
Milkii's [dotfiles](https://wiki.archlinux.org/index.php/Dotfiles)

a wee monorepo for all the .config n other config files

using a Stow-based workflow, all saved in one repo, within a dir with the app name

use `stow appdir` to link each directory & file to the dir above, `../`


* [GNU stow](https://www.gnu.org/software/stow)
* [Managing dotfiles with GNU stow](https://alexpearce.me/2016/02/managing-dotfiles-with-stow)
* https://github.com/mxmilkiib/dotfiles
